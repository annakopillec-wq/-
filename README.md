# Квест жизни

Личный планер в форме игры. Персонаж прокачивается от реальных дел по четырём характеристикам:
самостоятельная работа, здоровье и тело, досуг и радость, готовность к ЧП. Быт даёт общий опыт.

- `app/index.html` — исходник приложения (опубликован как Claude Artifact, данные синхронизируются через хранилище артефакта).
- Вне Claude страница работает в режиме «только на этом устройстве» (localStorage).

Шрифт: Gilroy, если он установлен в системе, иначе Manrope.
